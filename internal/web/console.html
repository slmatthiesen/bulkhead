Why the reasoning step is checkpointed too

A resumed agent must reach the state it was in. If it re-ran its model call it would sample a different answer, ask for different steps, and replay by step number would stop meaning anything — so model calls go through the control plane like every other step, and a resumed run is handed back the tokens it saw the first time.

It is also why a crash costs nothing: the model is not billed twice.
